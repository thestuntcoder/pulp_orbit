# Slice Garden

A cheerful, original, ad-free fruit-slicing game for family play. The entire game—styles, artwork, audio, and code—is contained in the single `index.html` file, with no accounts, trackers, external assets, or in-app purchases.

## Play

**Play online:** <https://thestuntcoder.github.io/fruit_shinobi/>

Or download and open `index.html` directly. To serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- **Touch / mouse:** press and drag through fruit; tapping a fruit also works.
- **Keyboard:** focus the garden, use ←/→ to choose fruit, then Enter or Space to slice.
- **Pause:** use the pause button, `P`, or `Escape`.
- **Calm mode:** replaces flying fruit with gently timed stationary fruit.

Scores and preferences are saved only in the browser's local storage.
